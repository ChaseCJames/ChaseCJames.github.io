04 · teaching

AI changes what is easy, not what matters.

Generating boilerplate is easy; understanding what the code does is still hard. Skills that are now easy can and should be off-loaded; skills that still matter must be taught and preserved deliberately, because they are no longer practiced incidentally.

Skills to preserve through unaided practice ranked by atrophy risk
01
Debugging with attention
The risk is not whether you use the agent — it is whether fixes land invisibly. The skill is reading each change and understanding why it works.
PRACTICEKeep a protocol with the agent: symptom → hypothesis → what changed → root cause. No fix accepted before the root cause is stated.
CADENCEEvery session
02
Reading code from scratch
The ability to read unfamiliar code is what lets you evaluate agent output critically.
PRACTICERead a substantial unfamiliar script. Write a brief summary. Only then, optionally, compare to what an agent says.
CADENCEMonthly
03
Foundational stats on paper
Statistical reasoning is the scientific skill most easily faked by an agent and most consequential when faked.
PRACTICEFor your highest-stakes analysis of the year, do the calculation yourself first. If your answer is wrong, that is information.
CADENCEAnnually, high-stakes
04
Writing the high-stakes paragraphs
Letting the agent draft your discussion is letting the agent decide what your work means.
PRACTICEDraft abstract, intro framing, and discussion yourself first — no agent, no chat history. Iterate with the agent after, but only once your own thoughts are on the page.
CADENCEPer manuscript
What does not change
Understanding
Knowing what a computation is doing, well enough to know whether it is doing the right thing.
Debugging
Forming and testing hypotheses about why something is failing.
Designing
Deciding how a problem should be decomposed into computational steps.
Reading
Looking at unfamiliar code and figuring out what it does.
Teaching sequence
  1. 01Reading first. Spend the first weeks reading existing analysis code. Have students explain each block in writing before they touch a keyboard.
  2. 02Generate-and-explain. Have students use an agent to generate small functions, then explain — without looking at the prompt history — what the function does and why.
  3. 03Debugging without an agent. Give students broken code; have them fix it unaided. Hardest to design; most important.
  4. 04Designing with an agent. Use an agent as a collaborator to design a small analysis, documenting every decision and its reasoning.
  5. 05Critiquing agent output. Give students agent-generated analyses with subtle errors and have them find the errors. Trains the skepticism the rest of the framework depends on.
Principle

Use AI from a position of independent competence.
