06 · where to start

From the chat window to full agentic coding.

If your AI use so far has been a chat window, agentic coding is a different relationship with the same models — same tools, different access and autonomy. The on-ramp below walks you through the shift.

Fig 6.1 · the on-ramp click a stage →
Chat Claude.ai · ChatGPT
·You describe the problem in a text box
·The model returns code as text
·You copy-paste into your editor by hand
·You run it, then paste errors back
·The model never sees your files or terminal
·Context is only what you remember to paste
Agent Claude Code · Codex
›You state a goal in the project itself
›The agent edits your files directly — you review diffs
›It runs commands and reads the output
›It iterates on errors without you relaying them
›It can navigate the whole repository
›Context is the live state of your project
same models — the difference is access and autonomy
Setup checklist:
01
A terminal or an editor— Terminal / iTerm · or VS Code / Cursor
02
Get comfortable: command line or GUI— ~30 min in a terminal, or just open the editor
03
git installed— the safety net for everything else
04
The agent— Claude Code / Codex: CLI or editor extension
05
An account / API access— subscription or API key
06
A workspace folder— a git repo the agent operates inside
Bring these from day onehover to highlight
Read the diff
Be critical when reading and reviewing the diff. The diff is the agent's actual proposal.  Note: In a science context it helps to hardwire a summary separate from the simple summary the agent provides. EXAMPLE every statistical analysis emits a PDF explaining the test, its parameters, and which were user-specified vs. agent-chosen.
Work under git
Branch for anything real. Commit small. Always be one command from undoing the last hour.
Sandbox first
New capability gets tried in a throwaway folder, not on data or code you cannot afford to break.
Distrust confidence
Confident output is the default, not a signal of correctness. Never accept what you cannot evaluate.
Keep the judgment
Delegate execution, not decisions. What is worth doing and what counts as evidence stay yours.
You are not starting over

Everything you learned getting good at chat — how to frame a question, when an answer smells wrong, how to push back — is exactly what makes you good at directing an agent. You are not starting over. You are widening the aperture.
