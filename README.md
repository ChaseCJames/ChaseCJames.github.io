Personal website for Chase James — Quantitative Ecologist, Postdoctoral Scholar at USC.

## Stack

Plain HTML/CSS/JS, served via GitHub Pages. No build step required.

```
index.html          — home / landing

research.html       — research overview
publications.html   — publications list
cv.html             — CV

css/                — styles
js/                 — scripts
img/                — images
```
